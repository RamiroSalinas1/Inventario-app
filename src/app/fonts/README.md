# Fuentes locales

Geist Sans y Geist Mono variables (peso 100–900), sin modificaciones, del paquete oficial [`geist@1.9.2`](https://www.npmjs.com/package/geist/v/1.9.2), mantenido en [vercel/geist-font](https://github.com/vercel/geist-font).

Se incluyen sólo los dos archivos WOFF2 necesarios y la licencia SIL Open Font License 1.1 en `LICENSE.txt`. No se agregó una dependencia npm. `next/font/local` integra y sirve las fuentes con Next.js y Vercel sin solicitudes a Google Fonts durante compilación o navegación.

Para actualizar, obtener la versión elegida mediante `npm pack geist@<versión>`, verificar su integridad y conservar los archivos originales y su licencia. Integridad SHA-512 del tarball utilizado:
